# 東京駅院（日本橋WASAMIビル）1階 玄関修正

「出店企画書と施設図面作成」プロジェクト用。会社パンフレットのセッションで作成したものを移管。

## 修正の前提
- 貸主の1階図面（工事区分表 3ページ）では、店舗入口は「道路側開放の玄関ポーチ＋奥の既設SUS製両開き扉（A工事）1組」。風除室はない。
- 道路側は開放、玄関ポーチは賃貸区画（98.36㎡）に含む（ユーザー確認済み）。
- 1F正面：アプローチ2,300／パネルA1,000／SSW-2 1,700／パネルA1,800（当社区画）＋ECP3,500／ビルエントランス4,000＝14,300。

## ファイル
- `1階_玄関修正版_図面一式（A-01_A-04_A-05_外装_内装）.pdf`：A-01 平面計画図、A-04 外観立面図・サイン計画図、A-05 専用アプローチ（玄関ポーチ）詳細図、P.8 外装イメージ、P.9 内装イメージ
- `images/`：外観3枚・内装1枚のイメージ画像、貸主図面の入口部分の確認画像
- `source/`：図面生成スクリプト（gen.py / gen2.py）、貸主1階図面のSVG、3Dイメージのシーン（three.js r160）

## 主な変更点
- 入口：風除室・ガラス扉の新設をやめ、既設扉1組のシンプルな玄関に。ポーチ内は造作なし。
- サイン：S2をポーチ脇壁（店舗用サインスペース）へ。店内正面の木調壁＋ロゴが既設扉越しに見える。
- 受付：扉の内側1,220mmを空け、正面の木調壁の前に配置。

## 確認事項（貸主・ビル管理）
既設扉の高さ・開き方／ポーチ床の段差・勾配／軒天高さ・ポーチ照明／サインスペースの寸法。寸法は貸主PDFからの読み取り値で、実施設計時にCADで確定。
