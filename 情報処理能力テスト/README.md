# 情報処理能力テスト（社内版）実施マニュアル

新卒採用で「情報処理能力」を測る社内独自の適性検査です。
`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動作し、インストールやネット接続は不要です。

---

## 1. 検査の概要

| 項目 | 内容 |
|---|---|
| 問題数 | 50問（5領域 × 10問）・五肢択一 |
| 制限時間 | 30分（全体） |
| 採点 | 自動採点（誤答の減点なし） |
| 出力 | 正答数・領域別得点・偏差値・情報処理指数・評価ランク（S〜D） |
| 不正検知 | 別タブ・別ウィンドウへの移動回数を記録／選択肢の並びを受験者ごとにシャッフル |

### 5つの領域

| 領域 | 測定する力 | IQ検査との対応 |
|---|---|---|
| A. 数列・規則性 | 数の並びから法則を見抜く | 流動性推理（帰納） |
| B. 言語・論理 | 条件を整理して正しく結論を導く | 言語理解・演繹推理 |
| C. 計数・資料解釈 | 表や数値から必要な値を素早く計算する | 数量推理・ワーキングメモリ |
| D. 図形・記号推理 | 記号や文字のパターンを抽象化する | 知覚推理 |
| E. 照合・処理速度 | 情報を正確・迅速に比較処理する | 処理速度 |

一般的な知能検査（WAIS等）の主要因子に対応させて構成しています。

---

## 2. 実施手順

1. **事前準備（試験官）**
   - `index.html` 内の `CONFIG.ADMIN_PIN`（初期値 `2027`）を必ず変更する。
   - 受験用PCで `index.html` を開き、受付画面が表示されることを確認する。
2. **受付**：受験者が受験番号と氏名を入力し「検査を開始する」を押す。
3. **受験**：30分経過で自動終了。途中で提出することもできる。
4. **終了**：受験者には得点を表示しない。「試験官メニュー」からPINを入力すると結果を確認できる。
5. **次の受験者**：試験官画面の「次の受験者へ」を押す。
6. **結果の回収**：「全記録をCSVで書き出す」でExcelで開けるCSVを保存し、`採用管理ツール/採用管理ツール_2026.xlsx` に転記する。

> 結果はそのPCのブラウザ内に保存されます。ブラウザの履歴削除・シークレットモードでは消えるため、実施日ごとに必ずCSVを書き出してください。

### 合理的配慮
障害等により配慮が必要な受験者には、`CONFIG.TIME_LIMIT_SEC` を延長（例：1.3倍＝39分）して実施してください。

## 3. 採点と結果の見方

| 指標 | 計算方法 |
|---|---|
| 正答数 | 50点満点 |
| 偏差値 | 50 + 10 ×（正答数 − 社内平均）÷ 標準偏差 |
| 情報処理指数 | 100 + 15 ×（正答数 − 社内平均）÷ 標準偏差 ※IQと同じ尺度（平均100・SD15） |
| 評価 | S：偏差値65以上／A：57〜64／B：43〜56／C：35〜42／D：34以下 |

### 基準値（ノルム）の更新 ― 重要
初期値は仮の値（平均32点・標準偏差7点）です。**受験者が30名以上集まったら**、CSVの「正答数」列から平均と標準偏差を算出し、`index.html` の `CONFIG.NORM` を書き換えてください。

```
Excel例：平均 =AVERAGE(D2:D100)　標準偏差 =STDEV.S(D2:D100)
```

これにより「自社の応募者集団の中での相対位置」が正しく表示されるようになります。

### 「情報処理指数」とIQについて
本検査の指数はIQと同じ尺度で表示しますが、**医学的・心理学的に標準化されたIQではありません**。社外（応募者への説明・求人票など）では「IQ」ではなく「情報処理能力テスト」「適性検査」と呼称してください。

## 5. 運用上の注意（法令・公正採用）

厚生労働省「公正な採用選考の基本」に照らし、以下を守って運用してください。

1. **職務との関連性を説明できること**：「業務で求められる情報処理能力を確認するため」と目的を明確にする。
2. **合否をこの検査だけで決めない**：面接・適性・経験と組み合わせた判断材料の一つとして用いる（足切りに使う場合も基準を事前に定め、全員に同一に適用する）。
3. **応募者への事前告知**：適性検査を実施すること、所要時間を案内する。
4. **個人情報の管理**：CSVは採用担当者のみがアクセスできる場所に保管し、保存期間を定めて削除する。
5. **妥当性の検証**：入社後1〜2年の評価と本検査の得点の相関を確認し、「本当に活躍を予測できているか」を毎年見直す。予測力の低い問題は差し替える。

### 問題の更新
問題が流出すると検査の意味がなくなるため、年度ごとに半分程度の問題を入れ替えることを推奨します。
CSVには問題ごとの正誤（A01〜E10列）が出力されるので、**正答率が95%超（易しすぎ）や20%未満（難しすぎ・悪問の可能性）の問題**から優先的に差し替えてください。
問題は `index.html` の `QUESTIONS` 配列に追加・修正できます（`a` は正解の選択肢番号、0始まり）。
