# 図形推理テスト（社内版）

3×3に並んだ図形の規則を見抜き、空いたマスに入る図形を選ぶ**行列推理（マトリクス）形式**の検査です。
国際的なIQテストでも使われる形式で、言語や知識に左右されにくく、論理的に情報を処理する力（流動性知能）を測ります。
問題はすべて社内用に独自に作ったものです。

| 項目 | 内容 |
|---|---|
| 問題数 | 30問＋例題1問（例題は採点しない） |
| 制限時間 | 25分 |
| 形式 | 8択。後半ほど難しくなる |
| 出力 | 正答数・偏差値・推定IQ・問題別の正誤と所要秒数（CSV） |

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 受験画面（ブラウザで開くだけで動作） |
| `items.js` | 問題データと図形の描画 |
| `解答一覧.html` | 試験官用の正解と規則の一覧（**受験者に見せない**） |
| `tools/verify.js` | 問題の検査（`node tools/verify.js`）。正解が1つに決まり、8つの選択肢がすべて見分けられるかを確認する |

## 実施手順
`../情報処理能力テスト/README.md` と同じです（受付 → 例題 → 本番25分 → 試験官PINで結果確認 → CSV書き出し）。
試験官PINの初期値は `2027`。`index.html` の `CONFIG.ADMIN_PIN` で必ず変更してください。

## 推定IQについて
- 推定IQ ＝ 100 ＋ 15 ×（正答数 − 社内平均）÷ 標準偏差。表示範囲は70〜145。
- 初期値は仮の値（平均15点・標準偏差5点）です。**受験者が30名以上になったら**、CSVの正答数から平均と標準偏差を計算し、`CONFIG.NORM` を書き換えてください。
- 標準化された公式のIQ（WAISやMensaの検査など）ではありません。社外では「IQ」ではなく「適性検査」と呼んでください。

## 選択肢の作り方（不正対策）
選択肢は「正解に3種類の誤りを0〜3個組み合わせた8通り」で作っています。
どの特徴（形・塗り・個数など）も、正しい値は選択肢の半分にしか現れません。そのため「選択肢に一番多く出てくる特徴を選ぶ」といった消去法では解けません。
選択肢の並びは受験者ごとにランダムに入れ替わります。

## 注意
正解は `items.js` から計算できます。**試験官が立ち会う会場実施**を前提にしてください。
公正採用（職務との関連の説明、合否をこの検査だけで決めない、入社後の評価との相関の検証）は情報処理能力テストと同じ考え方で運用してください。
