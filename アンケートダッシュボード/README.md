# 定例会アンケート リアルタイムダッシュボード

Googleフォーム「EOテニュア定例会の感想アンケート」の回答を、**送信された直後に**ブラウザで確認・分析できるページです。

- **分析サマリー**：回答数、満足度・活用度の平均点、LaLa／フォーラムの参加希望数、各設問の回答分布グラフ、回答数の推移、満足度×活用度のクロス集計
- **自由記述**：記述回答を新しい順に全件表示。よく出てくる言葉も表示
- **全回答一覧**：1人ずつ全項目（選択肢・点数・文章）を一覧表示。キーワード絞り込み、CSVダウンロード
- 5〜60秒ごとに自動更新（初期値10秒）。新しい回答が届くと通知が出て、該当行に「NEW」が付きます

## 点数のつけ方

5択の設問は、選択肢の上から順に **5点 → 1点** で点数化しています。

| 設問 | 5点 | 4点 | 3点 | 2点 | 1点 |
|---|---|---|---|---|---|
| 満足度 | 非常に満足 | 満足 | 普通 | やや不満 | 不満 |
| 活用度 | 非常に活かせそう | 活かせそう | どちらともいえない | あまり活かせない | 活かせない |

「時間・進行」「LaLa／フォーラムの参加意向」は点数をつけず、件数と割合で集計します（「その他」の記入は「その他」にまとめて集計）。

## セットアップ（約5分・一度だけ）

フォームのオーナーのGoogleアカウントで行います。サーバーやスプレッドシートは不要です。

1. Googleフォームの**編集画面**を開く
2. 右上の「⋮」→「**スクリプト エディタ**」（Apps Script）を開く
3. 最初からある `コード.gs`（Code.gs）の中身をすべて消し、このフォルダの **`Code.gs`** の内容を貼り付ける
4. 左の「ファイル」の「＋」→「**HTML**」→ 名前を **`index`** にして作成し、このフォルダの **`index.html`** の内容を貼り付ける
5. 💾 保存
6. 右上「**デプロイ**」→「新しいデプロイ」→ 種類「**ウェブアプリ**」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：下の「閲覧範囲」を参照
7. 「デプロイ」→ 権限の承認画面で自分のアカウントを選び「許可」
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」）
8. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）を開くとダッシュボードが表示されます

### 閲覧範囲（だれが見られるか）

| 設定 | 見られる人 |
|---|---|
| 自分のみ | フォームのオーナーだけ（いちばん安全） |
| Google アカウントを持つ全員 | URLを知っていて、Googleにログインしている人 |
| 全員 | URLを知っている人なら誰でも（回答内容が公開されるので注意） |

委員メンバーで共有する場合は「Google アカウントを持つ全員」にしてURLを共有するのがおすすめです。

### コードを修正したとき

「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「**新バージョン**」→「デプロイ」。URLは変わりません。

## そのほかの使い方

- **デモ表示**：`index.html` をそのままブラウザで開くと、架空のサンプルデータで画面を確認できます（15秒ごとに回答が1件増えます）。
- **別のサイトに置く場合**：`index.html` を任意の場所（GitHub Pages など）に置き、`index.html?api=（ウェブアプリのURL）` で開くと、そのURLから回答を取得して表示します。この場合、ウェブアプリのアクセス設定は「全員」が必要です。
- **別のフォームで使う場合**：Code.gs と index.html はフォームの設問を自動で読み取るので、他のフォームでもそのまま動きます。設問の短い見出しは `index.html` の `SHORT_NAMES` で変更できます。単独のApps Scriptプロジェクトから使う場合は `Code.gs` の `FORM_ID` にフォームIDを入れてください。

## ファイル

| ファイル | 内容 |
|---|---|
| `Code.gs` | フォームから設問と回答を読み取り、ダッシュボード画面／JSONを返す（Apps Script） |
| `index.html` | ダッシュボード画面（グラフは Chart.js） |
