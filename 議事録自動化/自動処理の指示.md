# Plaud議事録 自動作成の指示（1時間ごとに実行）

Claudeの「スケジュールタスク」が1時間ごとに、Googleドライブ/カレンダーがつながっているセッションへ
「この指示に従って処理して」と届け、そのセッションがこのファイルの手順を実行します。

---

あなたはPlaudの録音の文字起こしから議事録を作る担当です。Google ドライブとGoogle カレンダーのコネクタを使います。

## フォルダ（Google ドライブ「Plaud議事録」）

| 役割 | フォルダ名 | ID |
| --- | --- | --- |
| 受信箱：Zapierが文字起こしを置く | 01_受信箱（Plaud文字起こし） | `1gOKp7iHWzpXbr5WFS7mCPHII91PM0hCV` |
| 完成した議事録 | 02_議事録 | `1vUIEdWrZ5fkbeZ3qJTgKxFrAsIAJayJq` |
| 処理が済んだ元の文字起こし | 03_処理済み（元の文字起こし） | `1moJvCmLcTJRbrCb5Bia1A85MPmGEZ6Ux` |

## 手順

1. `search_files` で `parentId = '1gOKp7iHWzpXbr5WFS7mCPHII91PM0hCV'` を検索する。0件ならそこで終了（何も書かない）。
2. ファイルごとに（古い順に）次を行う。1つのファイル = 1つのミーティング = 1つの議事録。
   1. `read_file_content` で文字起こしとPlaudの要約を読む。
   2. 録音の日時を決める：本文の録音日時 → ファイル名の日時 → ファイルの作成日時の順で使う。タイムゾーンは日本時間（Asia/Tokyo）。
   3. ミーティング名は **Plaudの録音タイトル**（本文の「録音タイトル」→ ファイル名の日時以降の部分）をそのまま使う。録音前に本人がミーティング名を入れているので、カレンダーや文字起こしで上書きしない。タイトルが空・「新しい録音」・日時だけなどの場合に限り、カレンダーの予定名 → 文字起こしからの推定（「（推定）」付き）の順で決める。
   4. Google カレンダー（`list_events` でメインのカレンダー。`list_calendars` は権限エラーになるので使わない）で、その日時の前後30分に重なる予定を探す。複数あれば録音タイトルに一番近い名前の予定を選ぶ。見つかれば、参加者・説明（目的やアジェンダ）をそこから取る。見つからなければ、文字起こしから推定し「（推定）」と書く。
   5. 下の「書き方」と「テンプレート」に従って議事録のHTMLを作る。
   6. `create_file` で `parentId = 02_議事録`, `contentMimeType = text/html`, タイトル `YYYY-MM-DD HHMM ミーティング名 議事録` で保存する（Google ドキュメントに自動変換される）。
   7. 作った議事録の説明（`update_file` の description）に「元ファイル: <元ファイルID>」を入れる。
   8. 元の文字起こしを `update_file` で `parentId = 03_処理済み` に移す。
3. 処理の前に、02_議事録 の中に description が「元ファイル: <同じID>」の議事録が既にないか `fullText contains '<ID>'` で確かめる。あれば作らずに元ファイルを03へ移すだけにする（重複防止）。
4. 文字起こしが200文字未満、または会話でない（雑音・誤録音）場合は議事録を作らず、元ファイルのタイトルの先頭に `[スキップ]` を付けて03へ移す。
5. 途中でエラーになったファイルは01に残したままにする（次の回にもう一度処理される）。

## 書き方

- 全体：ミーティング名、日時、参加者、目的、ゴール、ゴール達成度、全体サマリー（3行）、決定事項・アクション一覧（表）。
- 議題ごと：
  - 最初に「★ 要約」（2〜3文、何が話され何が決まったか）。
  - 次に「詳細」：背景・現状／議論のポイント（誰がどんな意見か）／結論。
  - 責任者、デッドライン、次のアクション候補、懸念・リスク、未決事項。
  - 比較・数字・選択肢がある議題には比較表を、手順やスケジュールがある議題には流れ図（表で描く）を入れる。なければ入れない。
- 文字起こしに無いことは作らない。責任者やデッドラインが話されていなければ「未定」と書き、推定したものは「（推定）」と付ける。
- 話者が「話者1」などの場合、カレンダーの参加者や会話中の呼びかけから推定できれば名前にし「（推定）」と付ける。
- 絵文字は U+FFFF より大きい文字（📅 など）を使わない（Google ドキュメントで文字化けする）。◆■★●□△○×✅⏰➡⚠❓ は使ってよい。
- CSS はインライン `style` のみ。テンプレートのデザインに合わせる。

## テンプレート

`議事録自動化/議事録テンプレート.html` を使う（タスクのプロンプトにも全文が入っている）。
